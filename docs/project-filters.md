# Фильтр кейсов

Фильтр использует отдельное поле `projects.filter_categories` (`text[]`). Свободная категория, которая отображается на карточке и в описании, сохранена.

Перед публикацией обновлённой админки применить в Supabase обе миграции по порядку: `20261013000000_project_filters.sql`, затем `20261013010000_project_multiple_filters.sql`. Вторая переносит одиночные категории в массив и позволяет выбрать несколько. В рамках локальной разработки миграция на сервере не запускалась.

До миграции сайт показывает начальное распределение из `lib/project-filters.js`. Для сохранения категории в админке миграция обязательна. После миграции значение из базы имеет приоритет, включая пустой массив («Не указано»). Новые кейсы без категории и неразмеченные кейсы показываются только во «Все».

Начальное распределение:
- Брендинг: Designers Drama, редизайн Ассоциации студенческих СМИ, Студент года.
- Логотип: «Тәмлеме, дустым?».
- Сайт: Designers Drama, магазин Minem Kiem, сайт и афиша Милиана О'Войда.
- Афиши: киновечер, концерт KRISTIEE, сайт и афиша Милиана О'Войда.
- Полиграфия: подарочные боксы, одежда Minem Kiem, стикеры «Тайфун», бейджи.
- Не указано: баннер на арене, обложки Плейлиста студентов (отдельной категории для цифровых обложек пока нет).

Проверено: production build, переключение всех фильтров на актуальных кейсах в браузере, мобильный экран 390 px, приоритет явного сброса категории над начальной разметкой. Сохранение через админку в удалённую БД не проверялось, поскольку это изменило бы опубликованные данные.

В админке категории выбираются флажками. Если снять все флажки, кейс попадёт только во «Все». Активную плашку можно перетащить мышью или пальцем; выбор фиксируется при отпускании на ближайшем пункте.
